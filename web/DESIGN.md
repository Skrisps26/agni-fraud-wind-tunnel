# AGNI web — visual system

Operate mode: judges read **Identify → Generate → Defend** at a glance.

## World

**Case-file dossier** — warm paper ground, ink typography, thick rules. Looks like a fraud ops briefing packet, not a sci-fi dashboard. No glow, no canvas effects, no dark mode.

## Palette

| Role | Token | Value |
|------|-------|-------|
| Paper | `--paper` | `#f3ede4` |
| Card | `--card` | `#faf6ef` |
| Ink | `--ink` | `#1c1712` |
| Muted | `--muted` | `#6b6258` |
| Stamp / accent | `--stamp` | `#9e2a0e` |
| Caught | `--ok` | `#1f6b42` |
| Miss | `--bad` | `#9b1c1c` |

## Type

- **Stamp / logo:** Libre Baskerville 700
- **UI / body:** Libre Franklin 16px, line-height 1.55
- **IDs / metrics:** Inconsolata

## Layout

Flat grid of case-file panes separated by 1px rules. Loop strip is a simple numbered band. Mobile: tab rail with step numbers.

## Copy rules

Full-word metrics. Rules baseline = straw checklist, not Mastercard production.
